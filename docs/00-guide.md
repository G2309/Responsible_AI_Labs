# Instrucciones

Primera tarea: un paper LaTeX reproducible sobre SHAP

**ENTRADA — Modelo + caso**

* Clasificador de imágenes preentrenado o propio
* 1–3 imágenes de prueba
* Pregunta explicativa concreta

**LOOP CON CHATGPT — Construir y comprobar**

* Definir estructura → generar `.tex` → compilar → ejecutar SHAP → insertar resultados → revisar afirmaciones

**SALIDA — Paquete entregable**

* `paper.tex` + PDF
* Código/notebook SHAP
* Figuras y referencias
* Log de prompts + limitaciones
